# 🌤 Weather Dashboard

A modern and responsive **Weather Dashboard** that allows users to search for any city and instantly view real-time weather information including temperature, humidity, wind speed, pressure, sunrise, and sunset timings.

---

## 🚀 Features

- 🔍 Search weather by city name
- 🌡 Real-time temperature display
- 🤗 Feels Like temperature
- 💧 Humidity information
- 🌬 Wind speed
- 📊 Atmospheric pressure
- 🌅 Sunrise time
- 🌇 Sunset time
- 🌤 Dynamic weather icon
- ⏳ Loading animation while fetching data
- ❌ Error handling for invalid city names
- 📱 Fully responsive design
- 🎨 Modern glassmorphism UI

## 🔑 API Setup

This project uses the **OpenWeatherMap API**.

1. Create a free account at

```
https://openweathermap.org/api
```

2. Generate an API key.

3. Open `script.js`

4. Replace

```javascript
const API_KEY = "YOUR_API_KEY";
```

with

```javascript
const API_KEY = "YOUR_GENERATED_API_KEY";
```
